# LANTERN Control Room Dashboard

Control Room Dashboard for the LANTERN disaster SOS coordination platform, developed for TechHorizon 2.0.

## Project structure
- `client/` — Vite + React frontend
- `server/` — backend services and incident/rescue coordination logic
- `api/` — deployment entry point

## Setup
Install dependencies at the repository root and in `client/` using the included package manifests and lockfiles. Configure required environment variables locally; never commit secrets.

## Data note
Review mock/simulated data labels before presenting the dashboard as connected to live emergency services.
